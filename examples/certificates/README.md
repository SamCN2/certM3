# Certificate Examples

This directory contains example certificates generated by the CertM3 system for reference and testing.

## Files

### `example-with-groups.pem`
A canonical example certificate that demonstrates the group extension functionality.

**Certificate Details:**
- **Subject**: `CN = test151937`
- **Issuer**: `ogt11.com Root CA`
- **Validity**: 1 year (Jul 5, 2025 - Jul 5, 2026)
- **Group Extension**: OID `1.3.6.1.4.1.10049.2`
- **Groups**: `["test151937", "users"]`

**Verification:**
```bash
# Check for group extension
./check-group-oid.sh examples/certificates/example-with-groups.pem

# View certificate details
openssl x509 -in examples/certificates/example-with-groups.pem -text -noout
```

**Usage:**
This certificate serves as a reference for:
- Verifying group extension encoding
- Testing certificate parsing tools
- Demonstrating the expected certificate format
- Validating downstream systems that consume group information

## Group Extension Format

The group extension uses:
- **OID**: `1.3.6.1.4.1.10049.2`
- **Encoding**: ASN.1 SEQUENCE OF UTF8String
- **Critical**: false

This extension allows downstream systems to make authorization decisions based on the user's group membership encoded in the certificate.
